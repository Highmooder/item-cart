# Item cart

A student marketplace: plain HTML, CSS and JavaScript on Netlify, with Supabase for the database,
sign-in and Edge Functions.

| Folder / file | What it is |
|---|---|
| `*.html`, `css/`, `js/` | The website |
| `database/` | SQL files (run in order in Supabase) and setup guides |
| `supabase/functions/` | Edge Functions (payments, refunds, AI helper) |
| `netlify.toml` | Netlify settings and safety headers |
| `DEPLOY_SETUP.md` | How to deploy from GitHub to Netlify |

Start with `database/README.md`, then `DEPLOY_SETUP.md`, then `database/SECURITY_AND_LIMITS.md`
before you launch.
